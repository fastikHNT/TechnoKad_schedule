# Technokad_Schedule

## Описание проекта

**Technokad Schedule** — веб-приложение для управления графиками отпусков сотрудников ООО «ТехноКад». Система позволяет планировать и отслеживать отпуска, формировать отчёты в формате PDF, управлять пользователями и правами доступа через административную панель.

Основные возможности:
- Регистрация и авторизация пользователей с подтверждением по email
- Ролевая модель доступа (пользователь, администратор, супер-админ, разработчик)
- Создание и управление графиками отпусков по отделам
- Добавление и редактирование периодов отпусков
- Формирование PDF-отчётов по отпускам (по сотруднику, отделу, графику)
- Административная панель для управления пользователями
- Загрузка аватаров и редактирование профиля

## Сценарии использования

### 1. Регистрация нового пользователя

1. Перейдите на страницу авторизации: https://technokad.tech
2. Заполните форму регистрации (email, пароль, ФИО)
3. Перейдите по ссылке из письма, отправленного на указанный email
4. После активации Вы попадете в сервис автоматически

### 2. Создание графика отпусков

1. Авторизуйтесь в системе
2. Перейдите в раздел «Расписание»
3. Выберите отдел из выпадающего списка
4. Нажмите «Создать график»
5. Укажите название, год и добавьте сотрудников
6. Для каждого сотрудника добавьте периоды отпусков

### 3. Формирование отчёта

1. Перейдите в раздел «Отчёты»
2. Выберите график отпусков
3. Укажите область отчёта (по сотруднику, отделу, графику)
4. Задайте период (опционально)
5. Нажмите «Сформировать отчёт»
6. Скачайте PDF-файл

### 4. Управление пользователями (администратор)

1. Перейдите в раздел «Администрирование»
2. Просмотрите список всех пользователей
3. Нажмите на пользователя для редактирования (отдел, должность, роль)
4. Для деактивации пользователя нажмите «Удалить»
