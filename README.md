# Technokad_Schedule

## Описание проекта

**Technokad Schedule** — веб-приложение для управления графиками отпусков сотрудников ООО «ТехноКад». Система позволяет планировать и отслеживать отпуска, формировать отчёты в формате PDF и Excel, управлять пользователями и правами доступа через административную панель.

Основные возможно��ти:
- Регистрация и авторизация пользователей с подтверждением по email
- Ролевая модель доступа (пользователь, администратор, супер-админ, разработчик)
- Создание и управление графиками отпусков по отделам
- Добавление и редактирование периодов отпусков с проверкой ограничений
- Формирование PDF-отчётов по отпускам (по сотруднику, отделу, графику)
- Экспорт данных в Excel
- Административная панель для управления пользователями
- Загрузка аватаров и редактирование профиля
- Служебные записки на перенос отпуска
- Руководства пользователя и администратора



## Деплой на хостинг

### 1. Подготовка сервера

```bash
# Подключиться к серверу через SSH
ssh хост@ip_адрес_сервера

# Перейти в домашнюю директорию
cd /home/t/хост
```

### 2. Создание виртуального окружения

```bash
# Создать виртуальное окружение
python3.11 -m venv .flaskvenv

# Активировать его
source .flaskvenv/bin/activate

# Установить pip
python3 -m ensurepip --default-pip
```

### 3. Установка зависимостей

```bash
# Перейти в проект
cd public_html

# Установить зависимости
python3 -m pip install -r requirements.txt
```

### 4. Проверка приложения

```bash
# Проверить, загрузилось ли приложение
python3 -c "from app import app; print('OK')"
```

### 5. Настройка базы данных

- Загрузить базу данных на хостинг
- Изменить конфигурацию подключения в файле `config.py`

### 6. Настройка Nginx

```nginx
server {
    listen 80;
    server_name technokad.tech www.technokad.tech;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Статические файлы
    location /static {
        alias /home/t/хост/public_html/static;
        expires 30d;
    }

    # Аватары
    location /avatars {
        alias /home/t/хост/public_html/static/avatars;
        expires 30d;
    }
}
```

### 7. Запуск приложения

Использовать Gunicorn или uWSGI для запуска Flask-приложения.

### 1. Регистрация нового пользователя

1. Перейдите на страницу авторизации: https://technokad.tech
2. Заполните форму регистрации (email, пароль, ФИО)
3. Перейдите по ссылке из письма, отправленного на указанный email
4. После активации вы попадёте в сервис автоматически

### 2. Создание графика отпусков

1. Авторизуйтесь в системе
2. Перейдите в раздел «График отпусков»
3. Выберите отдел из выпадающего списка
4. Нажмите «Создать график»
5. Укажите название, год и добавьте сотрудников
6. Для каждого сотрудника добавьте периоды отпусков
7. Нажмите «Сохранить» для применения изменений

### 3. Планирование отпуска (для сотрудников)

1. Нажмите кнопку «Запланировать отпуск»
2. Кликните на нужный месяц в вашей строке
3. Выберите тип отпуска и даты
4. Система автоматически проверит ограничения:
   - Максимум 14 дней летом
   - Максимум 28 дней в год
   - Отсутствие конфликтов с коллегами
5. Нажмите «Сохранить»

### 4. Формирование отчёта

1. Перейдите в раздел «Формирование отчётов»
2. Выберите график отпусков
3. Укажите область отчёта (по сотруднику, отделу, графику)
4. Задайте период (опционально)
5. Нажмите «Сформировать отчёт»
6. Скачайте PDF-файл

### 5. Экспорт данных

1. Перейдите в раздел «Экспорт»
2. Выберите формат: PDF или Excel
3. Нажмите кнопку для загрузки файла

### 6. Управление пользователями (администратор)

1. Перейдите в раздел «Администрирование»
2. Просмотрите список всех пользователей
3. Нажмите на пользователя для редактирования (отдел, должность, роль)
4. Для деактивации пользователя нажмите «Удалить»
