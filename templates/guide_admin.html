Руководство администратора

Введение

Данное руководство предназначено для администраторов системы — пользователей с правами Админ, Супер-админ и Разработчик. Администраторы имеют расширенные права для управления сотрудниками и графиками отпусков.

Администрирование сотрудников

Перейдите в раздел "Администрирование" для управления списком сотрудников. Доступны следующие функции:

  • Поиск — быстрый поиск сотрудника по ФИО или email
  • Фильтр по отделу — отображение сотрудников выбранного отдела
  • Добавление сотрудника — добавление нового сотрудника в систему
  • Редактирование — изменение данных сотрудника (должность, отдел, телефон)
  • Удаление сотрудника — удаление из списка

Управление графиками отпусков

В разделе "График отпусков" администратору доступны дополнительные функции:

Создание графика

Нажмите "Создать график", выберите отдел, укажите название и год. Можно назначить график по умолчанию (отметив чекбокс).

Редактирование графика

Нажмите "Редактировать" для включения режима редактирования. Доступны:

  • Добавление сотрудника в график — выберите из списка зарегистрированных сотрудников или добавьте вручную
  • Удаление сотрудника из графика — выберите строку и нажмите "Удалить"
  • Редактирование ФИ — кликните на ФИО для изменения
  • Планирование отпусков — добавление, редактирование, удаление отпусков для любого сотрудника
  • Изменение порядка сотрудников — перетаскиванием (drag-and-drop)

Сохранение изменений

Все изменения сохраняются кнопкой "Сохранить". Отмена возвращает к исходному графику.

Удаление графика

Нажмите "Удалить график" для удаления выбранного графика.

Фильтры по направлениям

Для отдела ТП (технологический отдел) при добавлении сотрудников необходимо указать направление:

  • ПО/ЭЦП — программное обеспечение и электронная цифровая подпись
  • ТЭ/ТГ — технические средства и телекоммуникации
  • ТО/ТМ — техническое обслуживание и материальное обеспечение
  • ГРП — групповая обработка данных

Проверка ограничений при планировании

Система автоматически проверяет следующие ограничения при планировании отпусков:

  • Максимум 14 дней летом (июнь, июль, август) для одного сотрудника
  • Максимум 28 дней в год (без учёта учебного и декретного отпуска)
  • Несколько сотрудников одного направления не могут быть в отпуске одновременно
  • Руководитель и заместитель не могут быть в отпуске в одни и те же даты

Управление ролями и правами

В разделе администрирования можно управлять ролями сотрудников:

  • Пользователь — базовый доступ (просмотр своего графика)
  • Админ — управление сотрудниками своего отдела и графиками
  • Супер-админ — полный доступ ко всем отделам
  • Разработчик — полный доступ для администрирования и тестирования

Экспорт и отчёты

Администратор имеет полный доступ к функциям экспорта и формирования отчётов:

  • Экспорт в PDF — для печати и официальной отправки
  • Экспорт в Excel — для анализа данных
  • Отчёты по отделу — сводная информация по всем сотрудникам отдела
  • Отчёты по сотруднику — детализация отпусков конкретного сотрудника
  • Отчёты по подразделению — информация по структурному подразделению

Служебные записки

Администратор может создавать служебные записки на перенос отпуска для сотрудников. Для этого перейдите в раздел графика отпусков и нажмите "Служебная записка".

Безопасность

Система обеспечивает безопасность данных:

  • Авторизация через email и пароль с подтверждением reCAPTCHA
  • Токены активации аккаунта с ограничением по времени (1 час)
  • Одноразовые токены сброса пароля
  • Шифрование паролей с использованием werkzeug
  • Сессии с защитой от несанкционированного доступа
