О сервисе

Назначение системы

Данное веб-приложение — это система управления графиками отпускных периодов сотрудников, предназначенная для автоматизации планирования и учёта отпусков. Система позволяет эффективно организовывать рабочий процесс, избегая конфликтов и обеспечивая непрерывность бизнес-процессов.

Основной функционал

Администрирование сотрудников

Добавление, редактирование и удаление сотрудников, управление ролевым доступом

Графики отпусков

Создание и управление графиками отпусков по отделам и подразделениям

Учёт отпусков

Добавление, редактирование и удаление записей об отпусках сотрудников

Формирование отчётов

Генерация отчётов по выбранному графику: по отделу, сотруднику, подразделению

Экспорт данных

Выгрузка графиков отпусков в форматах PDF и Excel

Служебные записки

Формирование служебных записок на перенос отпуска

Ролевой доступ

Пользователь — просмотр общего графика отпусков отдела, планирование и редактирование своего отпуска, выгрузка актуального графика в удобном формате
Админ — администрирование списка новых сотрудников и сотрудников своего отдела, создание и редактирование графика отпусков, формирование служебной записки, отчеты по графику, выгрузка
Супер-админ — полный доступ ко всем отделам и функциям системы
Разработчик — полный доступ для администрирования и тестирования

Технологии

Система разработана с использованием Python (Flask) для серверной части, HTML/CSS/JavaScript для клиентской части. Для генерации PDF используется ReportLab, для работы с Excel — openpyxl. Процесс авторизации обеспечивается через Flask-Login с поддержкой токенов активации и восстановления пароля c использованием SMTP.
