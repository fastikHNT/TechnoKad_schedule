Руководство пользователя

Вход в систему

Для входа в систему используйте корпоративный email и пароль. При первом входе необходимо активировать аккаунт, перейдя по ссылке из письма на электронную почту. При восстановлении пароля используется одноразовый токен, отправляемый на email и действительный в течение 1 часа.

Просмотр графика отпусков

После авторизации вы автоматически попадаете на страницу "График отпусков". Система отображает график для вашего отдела. На графике отображаются:

  • ФИО сотрудников — в первых двух колонках таблицы
  • Должность — третья колонка таблицы
  • Периоды отпусков — цветные блоки в ячейках месяцев

Цвета блоков обозначают тип отпуска:

Основной отпуск
Учебный отпуск
Запланированный отпуск
Декретный отпуск

Планирование своего отпуска

Для планирования отпуска нажмите кнопку "Запланировать отпуск" в верхней панели. Вы сможете запланировать отпуск только для себя. Доступны следующие ограничения:

  • Максимум 14 дней летом (июнь, июль, август)
  • Максимум 28 дней в год (без учёта учебного и декретного)
  • Нельзя запланировать отпуск, если сотрудник вашего направления уже в отпуске
  • Отпуск не должен пересекаться с отпуском руководителя или заместителя

Для добавления отпуска кликните на нужную ячейку месяца. Откроется окно, где можно выбрать тип отпуска и даты. После заполнения нажмите "Сохранить".

Просмотр информации о сотруднике

Наведите курсор на блок отпуска, чтобы увидеть подробную информацию:

  • Даты начала и окончания отпуска
  • Общее количество дней
  • Тип отпуска

Экспорт графика

Для выгрузки графика отпусков перейдите в раздел "Экспорт". Доступны два формата:

  • PDF — для печати и отправки
  • Excel — для дальнейшей работы с данными

Выберите нужный формат и нажмите кнопку для загрузки файла.

Формирование отчётов

Раздел "Формирование отчетов" позволяет создать отчёт по выбранному графику. Доступны следующие варианты:

  • Отчёт по отделу
  • Отчёт по сотруднику
  • Отчёт по подразделению

Выберите фильтр и нажмите "Сформировать". Отчёт будет доступен для просмотра и экспорта.

Служебная записка на перенос отпуска

Для переноса отпуска можно создать служебную записку. Для этого:

  • Заполните данные руководителя (ФИО, должность, отдел)
  • Укажите свои данные
  • Укажите период текущего отпуска
  • Укажите период переноса
  • Укажите причину переноса

После заполнения нажмите "Сформировать". PDF-документ будет загружен автоматически.

Профиль пользователя

В правом верхнем углу находится ваш аватар. Кликните по нему для доступа к профилю:

  • Изменение пароля — нажмите "Изменить пароль" и введите новый пароль
  • Смена аватара — загрузите новое фото
  • Выход из системы — кнопка "Выйти"

Смена темы оформления

В нижней части бокового меню находится кнопка смены темы. Доступно три темы:

  • Фиолетовая — пурпурный градиент
  • Тёмная — чёрно-серая гамма
  • Синяя — сине-голубой градиент

Выбор темы сохраняется в браузере.
